# CartIT Customer Web Application `cartit-frontend(web)`

A modern, production-grade 10-minute instant grocery e-commerce web application matching the **CartIT Mobile App** and aligned with the **Verdant Grocery Logic** design system (`DESIGN.md`).

## 🚀 Tech Stack
- **Framework**: React 19 + Vite + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Design Tokens (`DESIGN.md`)
- **Icons**: Lucide React
- **Backend API**: Integrated with CartIT Spring Boot Backend (`http://localhost:8080/api` / Render URL)

## 🛒 Features
1. **Header & Navigation**: Location Selector, Search Bar with Auto-complete, Cart Counter Badge, Auth Modal Trigger.
2. **Interactive Banners & Categories**: Instant 10-Min Delivery Tag, Seasonal Discounts, Category Filters.
3. **Product Catalog & Grid**: Product Cards with Instant Quantity Stepper, Discount Badges, Unit Metrics.
4. **Product Detail Modal**: High-res image gallery, stock availability, nutritional details, customer reviews.
5. **Cart Drawer**: Real-time bill calculation, Delivery & Handling fee rules, Coupon code applicator, Delivery instructions.
6. **Seamless Checkout**: Address management (Home/Work/Other), Payment Options (UPI, Card, Netbanking, COD).
7. **Live Order Tracking**: Step-by-step order progress timeline, Driver info, Map view simulation.
8. **User Auth**: Google OAuth & Phone OTP Login matching CartIT Backend.
